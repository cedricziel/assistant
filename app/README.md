## App icons

Two source files at the root of this directory drive all generated web/PWA
icon assets:

- `icon_source.png` — 1024×1024, full-bleed brand artwork. Source for
  `web/favicon.png`, `web/icons/Icon-192.png`, and `web/icons/Icon-512.png`.
- `icon_source_maskable.png` — 1024×1024, opaque `#080C1A` background filling
  all four corners with the brand logo centered at ~70% scale within the inner
  safe zone. Source for `web/icons/Icon-maskable-192.png` and
  `web/icons/Icon-maskable-512.png` so Android mask shapes don't expose
  transparency.

Regenerate all derived web/PWA icons from these sources with `make icons` at
the repo root. The target uses `flutter_launcher_icons` for the standard
variants and `sips`/`magick` for the maskable variants. Native iOS, macOS,
and Android launcher icons are not regenerated by `make icons`.
